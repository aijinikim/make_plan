# 브레인스토밍 기법 (발산 단계)

## 철칙
- **비판 금지.** "그건 안 될 것 같아" 대신 "그게 된다면 뭐가 필요할까?"
- **양이 질을 만든다.** 원석은 최소 15개 이상 모은다.
- **한 번에 질문 하나.** 기법은 질문마다 바꿔 지루함을 막는다.
- **DJ가 먼저 엉뚱한 예시 1~2개를 던진다.** 사용자가 백지에서 시작하지 않게 한다.
- 사용자의 답을 그대로 받지 말고 **리믹스**한다: "오, 그걸 ○○랑 섞으면?"

## 기법 카드 (순환 사용)

### 1. SCAMPER
| 키 | 질문 예시 |
|---|---|
| S 대체 | "이 과정에서 사람 대신 AI가, 화면 대신 소리가 하면?" |
| C 결합 | "이거랑 전혀 상관없는 ○○ 앱을 합치면?" |
| A 응용 | "게임/병원/편의점에서는 이 문제를 어떻게 풀고 있지?" |
| M 확대·축소 | "1000배 크게? 손톱만 하게?" |
| P 다른 용도 | "이걸 할머니가 쓰면? 강아지가 쓰면?" |
| E 제거 | "가장 핵심이라 믿는 기능을 빼면 뭐가 남지?" |
| R 뒤집기 | "순서를 거꾸로 하면? 사용자가 제공자가 되면?" |

### 2. 역발상 (Reverse)
"이 문제를 **최악으로 만드는** 방법 10개는?" → 하나씩 뒤집어 해결책으로.

### 3. 엉뚱가정 (What If)
- "만약 중력이 없다면?" / "만약 모두가 투명 인간이라면?"
- "예산이 무한이라면?" / "예산이 0원이라면?"
- "이 서비스가 2077년에 있다면?"

### 4. 6색 모자
하양(사실) · 빨강(감정) · 검정(위험, 발산 단계에선 마지막에만) · 노랑(장점) · 초록(창의) · 파랑(정리). 한 질문에 한 색만.

### 5. 페르소나 빙의
"스티브 잡스라면? 초등학생이라면? 악당이라면? 외계인 관광객이라면?"

### 6. 랜덤 단어 결합
아래 단어 중 하나를 무작위로 뽑아 강제 연결: 고양이, 우주, 편의점, 날씨, 냄새, 타임머신, 밈, 픽셀, 노래방, 식물, 지하철, 꿈, 거울, 택배, 할머니, 로봇, 사진, 시계, 비밀, 축제.

### 7. 스케일 점프
"나 혼자 → 우리 반 → 우리 동네 → 전국 → 전 세계"로 사용자 범위를 바꿔가며.

### 8. 감각 전환
"이걸 **듣는** 서비스로? **만지는**? **냄새 맡는**? 화면 없이?"

### 9. 트렌드 믹스
지금 뜨는 것(AI 에이전트, 픽셀아트, 숏폼, 로컬, 헬시플레저, 커뮤니티, 굿즈, 레트로 등)과 아이디어를 섞는다. 필요하면 dj-researcher로 최신 트렌드를 검색한다.

## 원석 관리
- 3~4문마다 지금까지 나온 원석을 번호 목록으로 보여준다: `💎 원석 #1 …`
- 엉뚱할수록 🔥를 붙여 칭찬한다.
- 사용자가 "정리해"라고 하거나 원석이 15개 이상이면 3단계(📌 고르기)를 제안한다.
